# ChatGPT-project: Mijn Kookboek

Maak in ChatGPT een project met de naam **Mijn Kookboek**. Voeg deze conversatie
toe als de app die mogelijkheid biedt. Gebruik daarna aparte gesprekken voor
**Recepten**, **Websiteontwikkeling** en eventueel één gesprek per grotere wijziging.
De GitHub-koppeling moet in de gebruikte gesprekken beschikbaar zijn.

Bewaar de repositorylink als projectbron of in de projectinstructies. Een ZIP met
code is alleen een momentopname; laat de assistent steeds de actuele GitHub-versie
lezen. Een ChatGPT-project synchroniseert niet automatisch alle GitHub-bestanden.
Er is vanuit de beschikbare tools geen project aangemaakt of instructie ingesteld.

## Projectinstructies om over te nemen

Je helpt mij met mijn kookboek op GitHub Pages. De actuele bronrepository is
https://github.com/tammosopar/Mijn-kookboek. Lees vóór wijzigingen AGENTS.md,
README.md en docs/werkwijze.md uit de actuele repository. Volg die afspraken.

De productiesite is https://tammosopar.github.io/Mijn-kookboek/.
De acceptatierepository is tammosopar/Mijn-kookboek-preview; controleer vóór gebruik
of deze bestaat en of de deployment geslaagd is.

Wanneer ik vraag een recept toe te voegen en te publiceren, valideer en sla dan
alleen dat recept op main op en controleer de publicatie. Verzin geen eigen notities
namens mij. Controleer bestaande recepten om duplicaten te voorkomen.

Voor wijzigingen aan uiterlijk of gedrag: werk op een aparte branch, open een PR,
voer controles uit en publiceer de exacte kandidaat op acceptatie. Wacht op mijn
akkoord op die versie voordat je naar productie publiceert. Houd recente recepten
op main in stand. Bevestig livegang pas na een geslaagde deployment.

Houd blijvende afspraken en de wensenlijst in GitHub bij. Claim nooit dat een
instelling, preview of publicatie is afgerond zonder dat te controleren.
